# PiiS Road Site

就労継続支援B型の業務支援ツールの操作デモです。

## デモの機能

- 作業予定の作成と電子ホワイトボード
- 出欠、実作業時間、本人の様子・対処、支援メモの記録
- 作業時間の自動計算と月次工賃概算
- 個別支援計画書の作成・A4縦印刷

架空の利用者と仮の工賃単価を使用しています。入力は閲覧者のブラウザ内（localStorage）に保存され、他の閲覧者とは共有されません。実利用者の情報を入力しないでください。

Google Sheetsへの保存、音声文字起こし、AI文章生成、請求ソフトとの正式連携はこの公開デモには含まれません。

## GitHub Pagesでの公開

1. このフォルダ内の index.html と .nojekyll をリポジトリの直下へ配置します。
2. Settings → Pages → Source を「Deploy from a branch」にします。
3. Branch を main、フォルダを /(root) にして Save を押します。
4. 公開完了後、Pages画面の「Visit site」からデモを開きます。

## 操作例

1. 「予定をつくる」で仮案作成 → 予定を確定・掲示。
2. 「実績を記録」で作業・開始終了時刻・休憩・本人の様子・対処を入力。
3. 記録済みにチェックし、画面右上で保存。
4. 月次集計や支援計画書の作成・印刷を確認。

デモ内のデータを初期化する場合は、このサイトのブラウザ保存データを削除します。
